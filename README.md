# AX Sprint Control Tower MVP v5

## 이번 버전 변경사항

- 기관 업무현황 상단 기관 탭 유지
- 기관별 현재 수행업무, 마감일, 완료기준 중심 화면 유지
- `요청사항 및 기관 회신` 영역 추가
  - 요청기관 / 수신기관
  - 요청일 / 회신기한
  - 요청사항
  - 기관 회신내용 / 회신일
  - 요청기관 확인 메모
  - 처리상태
- `소통 메모` 추가
  - 기관별 업무 메모 스레드
  - 관련 실행과제 연결
  - 작성기관·작성일 표시
  - 답변 및 추가 메모를 시간순으로 누적
- 좌측 메뉴에 `요청·회신`, `소통 메모` 별도 관리화면 추가
- 기존 v4 LocalStorage 데이터가 있으면 자동으로 불러오도록 마이그레이션 처리

## 운영 개념

기관 업무현황은 참여기관이 자기 기관의 업무를 확인하는 화면입니다.

정션메드가 별도 조치나 확인을 요청하면 `요청사항`으로 등록하고 회신기한을 지정합니다. 참여기관은 해당 요청에 처리결과·일정·확인내용을 `기관 회신`으로 작성합니다. 정션메드는 회신을 확인한 뒤 추가 요청 또는 종결 여부를 `요청기관 확인 메모`에 기록합니다.

정식 요청으로 관리할 필요가 없는 협의사항, 확인 메모, 간단한 답변은 `소통 메모`에서 기관별 스레드로 관리합니다.

## 현재 저장 방식

MVP v5는 브라우저 LocalStorage에 저장됩니다. 한 브라우저에서 입력한 데이터는 해당 브라우저에만 저장됩니다.

여러 기관이 GitHub Pages에서 공동으로 사용하려면 다음 단계에서 Supabase 등 공용 데이터베이스를 연결해야 합니다.
