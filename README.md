# AX Sprint Control Tower MVP v14

기관용 화면과 관리자용 화면이 동일한 로컬 데이터 구조를 사용하는 프로토타입입니다.

## v14 변경사항

- 기관 선택 영역의 선택 탭 하단 강조 장식 제거
- `전체 항목`을 단일 목록 형태로 재구성
- `전체 / 기한 경과 / 마감 임박 / 진행 / 예정 / 완료` 보기 선택 추가
- 각 항목 앞에 작은 상태 태그 표시
- 항목을 클릭하면 해당 분류의 `상세 현황`으로 이동하고 선택 항목을 강조 표시
- 완료 항목도 클릭하여 상세 내용을 확인할 수 있도록 연결

## 기관별 직접 링크

- `junctionmed.html` : 정션메드
- `kyungbok.html` : 경복대학교 산학협력단
- `carefuture.html` : 돌봄과 미래
- `aimlab.html` : 에임랩

기관 화면 우측 상단 `관리자` 버튼을 누른 뒤 비밀번호 `0000`을 입력하면 통합 관리자 화면으로 진입합니다.

## 실행

압축을 푼 뒤 `index.html` 또는 각 기관별 HTML 파일을 브라우저에서 열면 됩니다.

현재 데이터 저장 방식은 브라우저 `localStorage`입니다. 실제 GitHub Pages 공동 운영 시에는 Supabase 등 공용 데이터베이스 연결이 필요합니다.


## v14 관리자 화면 정리
- 관리자 사이드바를 밝은 중성색으로 변경
- 상단 버튼과 상태색 대비 완화
- 핵심지표 5개를 하나의 요약 바 형태로 정리
- 기관 화면 바로가기를 얇은 바로가기 스트립으로 축소
- 표, 성과카드, 기관카드의 테두리와 색 대비를 낮추고 여백을 통일
- 기관용 화면 구조와 기능은 v13을 유지
