# AX Sprint Control Tower MVP v17

v17은 관리자 통합 대시보드의 가독성과 반응형 균형을 재정비한 버전입니다.

주요 변경사항
- 성과영역 현황과 주요 확인사항의 데스크톱 비율 재설계
- 주요 확인사항에서 항목명이 글자 단위로 줄바꿈되는 현상 수정
- 두 패널 높이를 독립적으로 처리해 불필요한 빈 공간 제거
- 주요 확인사항은 우선 6건만 표시하고 나머지는 전체 실행항목으로 연결
- 성과영역명, 설명, 상태값, 확인사항 글자 크기 재조정
- 1450px 이하에서는 성과영역과 주요 확인사항을 세로 배치
- 태블릿/모바일에서는 성과영역 진행률과 확인사항을 2단 구조로 자동 재배치
- 기관별 현황 카드는 4열 → 2열 → 1열로 반응형 전환
- 기관용 화면과 기존 데이터 구조는 유지

관리자 비밀번호: 0000
